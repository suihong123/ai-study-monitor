## 11. 只读证据 SQL

以下 SQL 只用于隔离测试项目；将 `<TEST_CODE>` 替换为专用真机测试码。查询不返回完整会话令牌，只返回是否存在及摘要。

### 11.1 权益、当前环境与令牌摘要

```sql
begin transaction read only;

select
  code,
  plan_type,
  total_minutes,
  used_minutes,
  greatest(total_minutes - used_minutes, 0) as remaining_minutes,
  status,
  device_id,
  current_device_name,
  current_device_model,
  current_device_platform,
  device_bound_at,
  rebind_total,
  last_rebind_at
from access_codes
where code = '<TEST_CODE>';

select
  count(*) as historical_sessions,
  count(*) filter (where status = 'active' and end_time is null)
    as active_sessions,
  count(*) filter (where session_token is not null)
    as sessions_with_token,
  max(left(encode(digest(coalesce(session_token, ''), 'sha256'), 'hex'), 12))
    as latest_token_hash_prefix
from sessions
where access_code_id = (
  select id from access_codes where code = '<TEST_CODE>'
);

rollback;
```

### 11.2 最近重新绑定审计

```sql
begin transaction read only;

select
  created_at,
  action_source,
  left(idempotency_key, 12) as request_id_prefix,
  old_device_id,
  old_device_name,
  old_device_model,
  old_device_platform,
  new_device_id,
  new_device_name,
  new_device_model,
  new_device_platform,
  window_count_before,
  window_count_after,
  next_available_at,
  success,
  result_code,
  failure_reason
from device_rebind_logs
where access_code = '<TEST_CODE>'
order by created_at desc
limit 30;

select count(*) as successful_user_rebinds_in_15_days
from device_rebind_logs
where access_code = '<TEST_CODE>'
  and action_source = 'user'
  and success = true
  and result_code = 'rebound'
  and created_at >= now() - interval '15 days';

rollback;
```

### 11.3 场景 4：旧会话停止证据

数据库只能证明旧令牌失效和会话收口，不能单独证明摄像头、声音、定时器已停止。该场景必须同时保存手机端页面录屏或截图、Network 请求时间线和下列只读结果：

```sql
begin transaction read only;

select
  id,
  start_time,
  end_time,
  status,
  duration_minutes,
  last_active_at,
  session_token is null as token_cleared
from sessions
where access_code_id = (
  select id from access_codes where code = '<TEST_CODE>'
)
order by created_at desc
limit 10;

select
  created_at,
  result_code,
  success,
  old_device_id,
  new_device_id,
  window_count_before,
  window_count_after
from device_rebind_logs
where access_code = '<TEST_CODE>'
order by created_at desc
limit 10;

rollback;
```

验收证据中仍需人工确认：重新绑定后手机不再出现新的分析或心跳请求，摄像头指示熄灭、声音停止、本地监督状态清除、页面返回首页并显示正确提示。
