## 维护原则

- 代码是功能事实的最终依据，线上数据是业务事实的最终依据。
- 文档必须标明“事实、判断、未知”，不以愿景代替现状。
- 产品规则或业务口径变化时，相关代码和基线文档必须在同一轮更新。
- 基线用于减少重复解释，不替代每次优化对当前代码和数据的重新核对。
